## Important
This is a branded public beta. Previous One UI 8 and One UI 9 testing does not establish universal compatibility. The Balanced-mode issue has not been investigated or fixed in this branding update. Unsupported firmware-specific controls may open original Samsung settings.

Scope LSPosed to Samsung Device Care only. Debug signing may require uninstalling older APKs before updating. If needed, disable the module and reboot to recover the stock interface.
