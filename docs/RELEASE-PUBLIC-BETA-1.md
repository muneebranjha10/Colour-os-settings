# ColourOS Battery v1.1 — Public Beta 1

Made by Muneeb.

A separate public beta package based on RC10 Liquid Lens. On the first visit to Settings > Battery, users see a full-page beta warning and Continue button. Acknowledgment is saved locally in Device Care preferences and normally persists across visits, reboots and updates. Clearing Device Care data resets it. No analytics or network permission.

This APK is on the public-beta branch and uses the same application ID as RC10 so the builds cannot run simultaneously. An uninstall/reinstall may be needed if debug signatures differ. Enable the module in LSPosed, scope Samsung Device Care only, and reboot.

39 automated tests plus source wiring and APK signature checks. Device compatibility, actual rendering and battery accuracy still need testing. If problems occur, disable the module and reboot. All Samsung Galaxy models targeted; compatibility is in testing.
